# AutoApply downloads

Installers for [AutoApply](https://autoapply.acoderyessir.workers.dev), the desktop app that applies to LinkedIn Easy Apply jobs for you.

Download the latest version from the **Releases** page on the right:

- **Mac (Apple Silicon)** — `AutoApply-mac-arm64.dmg`
- **Mac (Intel)** — `AutoApply-mac-intel.dmg`
- **Windows 10/11** — `AutoApply-Setup.exe`

You need a license key to use the app. Buy one at https://autoapply.acoderyessir.workers.dev.

Windows shows "Windows protected your PC" for new apps: click **More info → Run anyway**.
